# Project Registry

One page that lists every Bizgrowth GitHub repo (public and private) with a goal, status, category and notes for each.

- Single file: `index.html` (no build step, no dependencies).
- Hosting: any static host (Vercel: import this repo, framework "Other", no build command).
- Private repos: click "GitHub token" and paste a token (fine-grained, All repositories, Metadata read-only). The token stays in your browser.
- Goals/notes are saved in your browser. Use Backup / Restore to keep a copy.
