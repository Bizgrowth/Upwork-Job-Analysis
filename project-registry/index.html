GitHub token

Paste a GitHub token so the registry can list your private repos too. It is saved only in this browser and sent only to api.github.com.

Create one at GitHub → Settings → Developer settings → Personal access tokens. A fine-grained token with Repository access: All repositories and Metadata: Read-only is enough (a classic token needs the repo scope).
